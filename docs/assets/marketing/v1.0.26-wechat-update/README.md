## 建议配文

`more-paper-workflow` 是我整理的一套学术论文全流程 Skill，不是“一键生成论文”的提示词包，而是把定题、大纲、检索、PDF、Zotero、证据化写作、科研图表、引用审计和保守润色放进同一条可回查链路里。

已有 DOI、PDF、Zotero 文库、证据包或章节草稿时，可以直接从对应 Step 开始；但证据边界、Checkpoint 和质量门不会被跳过。

这两天又把 Step 7/8 加固了一轮：

昨天解决公式写作和 DOCX 原生公式退化问题，今天把论文流程图/架构图原生接进 Step 7，并补上黑白无底纹、字号和证据哈希质量门。

这次不是纯功能堆叠，而是把已经验证过的 Step 7 绘图效果固化下来：从 PDF 证据提炼方法架构，生成可审阅、可投稿的黑白流程图，并把“黑白、无底纹、字号合适、布局可查”纳入默认质量门。

它不是让 AI 一键写论文，而是让研究问题、证据、公式、图表和终稿检查在同一条可回查链路里工作。
