## Reply 1: Why

```text
The problem is not text generation.

Research needs evidence matched to claims, citations checked at the right depth, explicit gaps, and auditable revisions.

AI can draft. Research must stay traceable.

中文：AI 可以起草，研究必须可追溯。
```

## Reply 2: Start

```text
Start with what you already have:

• DOI / URL / BibTeX → Step 5
• PDF / Zotero → Step 6–7
• Draft → Step 8

No forced restart. No skipped quality gates.

中文：已有材料可直接进入对应步骤。
```
